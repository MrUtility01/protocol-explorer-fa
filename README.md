# کاوشگر پروتکل (Protocol Explorer فارسی)

نسخهٔ ساده و فارسی ابزار تعاملی یادگیری پروتکل‌های اینترنت.

الهام‌گرفته از [Protocol Explorer](https://protocol-explorer-alpha.vercel.app/) ساختهٔ Dilum Sanjaya.

## ویژگی‌ها

- رابط کاملاً فارسی و راست‌چین (RTL)
- چهار پروتکل اصلی: HTTP، DNS، TCP، HTTPS
- دیاگرام شبکه + انیمیشن ساده پکت‌ها
- جدول جریان پکت‌ها
- کنترل پخش، گام‌به‌گام و سرعت
- توضیح هر پروتکل و مراحل آن

## اجرا

```bash
npm install
npm run dev
```

باز کردن http://localhost:3000

## دیپلوی روی Vercel

۱. به [vercel.com](https://vercel.com) برو و با گیت‌هاب لاگین کن
۲. New Project → این ریپازیتوری را انتخاب کن
۳. Deploy بزن
